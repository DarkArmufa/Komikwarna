V10: USER EGG CHANGER + SAKLAR ON/OFF + NOTIFIKASI GLOBAL + {user}

COMIC PTERO — USER EGG CHANGER BY NEST

1. Ekstrak ZIP ke folder terpisah.
2. Panel sudah ada: sudo bash INSTALL-THEME.sh
3. Login sebagai admin utama user ID 1.
4. Buka Admin > Settings > Eggs Changer.
5. Nyalakan saklar "Changer Eggs untuk user" lalu centang ID Nest yang diizinkan dan Save.
6. Jika server user memakai Nest yang dicentang, menu "Changer Eggs" otomatis muncul di menu server user.
7. User hanya dapat mengganti Egg ke Egg lain yang masih berada di Nest server tersebut. User tidak bisa mengganti Nest.
8. Saat Save, startup command, Docker image utama, dan variable Egg disesuaikan ke default Egg baru. File server tidak dihapus dan server tidak otomatis reinstall.
9. Disarankan user Stop server sebelum mengganti Egg.
10. Pengaturan Nest hanya dapat diubah oleh admin ID 1.

Fitur sebelumnya tetap ada:
- API PTLA/PTLC tidak ditampilkan di drawer.
- Papan notifikasi global di halaman client kecuali Admin.
- Welcome mendukung token {user}.
- Link layanan di menu kanan.

Installer: sudo bash START-INSTALLER.sh
Update theme: sudo bash UPDATE-THEME.sh
Uninstall: sudo bash INSTALL-THEME.sh --remove
